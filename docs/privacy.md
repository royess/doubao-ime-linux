# 数据与运行边界

- 键盘按键进入官方闭源引擎。该引擎可能使用云候选、遥测等联网功能，本项目未审计其全部网络行为，不宣称完全离线。
- 可选语音会将录音发送至豆包语音服务。只有主动开始听写后才打开录音流，空闲时不录音。
- 语音桥接不保存转写正文到运行状态，也不主动录制 WAV；提交文本只发送给当次有效的 Fcitx 输入框。
- 语音状态和服务日志包含快捷键动作、取消原因、录音时长、音量峰值、结果字数和脱敏错误类别，用于排障；不记录音频、转写正文或上游原始错误消息。
- 官方引擎、Wine 和设置程序可能产生自己的缓存、词库和日志，它们位于本项目独占的状态目录。该目录包含个人数据，不应发布。
- 外部适配器的设备凭据保存在状态目录的 `private/credentials.json`；首次使用可能进行设备注册，错误不会触发桥接主动轮换设备身份。
- Wine prefix 和 Xvfb 用于进程及显示隔离，**不是安全沙箱**。官方 Windows 组件仍以当前 Linux 用户权限运行。
- 键盘 socket 限制为同一用户访问；语音提交要求相同 D-Bus 调用方、有效焦点和一次性许可。这些检查防止误提交，不是对本机同用户恶意程序的完整防护。
- 卸载保留状态目录，便于以后恢复。公开问题报告时只附已脱敏的错误摘要。
