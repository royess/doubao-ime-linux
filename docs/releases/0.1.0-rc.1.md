## English

First source preview of an unofficial Fcitx 5 bridge for the official DoubaoIME
Windows **0.9.0.0** keyboard engine.

- Native Fcitx preedit, candidates, selection and segmented conversion.
- Optional official settings window in a separate Wine Mono environment;
  keyboard changes are merged when it closes.
- Optional Linux voice coordinator and focus-bound text delivery. The external
  ASR adapter must be supplied separately.
- Separate English and Chinese READMEs, reversible installation, and automated
  GCC/Clang, unit, Fcitx/GTK fixture, installation and source-package checks.

**Source only:** download `doubao-ime-linux-0.1.0-rc.1.tar.gz` and `SHA256SUMS`.
No official binaries, Wine, fonts, dictionaries, credentials or recordings are
included. This is not a ready-to-run binary package.

Official-engine testing used Arch Linux x86_64, Fcitx 5.1.22 and Wine 11.17.
CI uses a mock engine and does not test live ASR. Windows settings parity is
incomplete; account synchronization, long-running stability and other platforms
remain unverified. The RPC interface is tied to the supported official version.

## 简体中文

首个源码预发布版本：将官方豆包 Windows 输入法 **0.9.0.0** 的键盘引擎接入 Fcitx 5。
包含原生预编辑和候选词、独立运行的官方设置窗口、可选语音协调器、中英文 README
及自动化测试。语音适配器需要用户另行提供。

附件只有源码与校验文件，**不是解压即用的二进制安装包**。不包含官方程序、Wine、
字体、词库、凭据或录音。使用前按 README 安装依赖并提供指定版本的官方安装包。

官方引擎已在 Arch x86_64 / Fcitx 5.1.22 / Wine 11.17 下验证。CI 使用模拟引擎，
不代表云端语音可用性检查。Windows 设置尚未完全接入，账号同步、长期稳定性及
其他平台仍有限制；官方升级后需要重新验证接口。

