# 官方设置的可用范围

**原生设置中有实际生效的选项，但并非所有 Windows 选项都已适配 Linux。**
界面仍会显示未适配的选项；能勾选或保存某个选项，不代表它会改变 Linux 下的输入行为。

安装时使用 `--settings` 后，可以运行 `doubao-settings`，从应用菜单打开
「豆包输入法设置（官方）」，或切换到豆包后，从 Waybar 等托盘中的 Fcitx 菜单
点击「豆包设置」（托盘入口需要 `gio`）。

设置窗口使用独立 Wine prefix、Wine Mono 11.3.0 和 Noto Sans CJK SC。
Windows 官方 EXE/DLL 保持原样，C# 启动器调整 WPF 字体选择；独立的临时引擎服务提供设置 RPC。

**键盘设置在正常关闭窗口后应用，不是在点击选项时立即应用。**
打开 `doubao-settings` 时复制当前键盘配置。关闭窗口后只合并本次改变的原有 `keyboard` 字段，
保留其他分类与并发修改；同字段冲突、类型变化或 UI 异常退出会停止应用。
新增未知字段及语音、外观等其他配置分类不会合并到活动引擎配置。
备份在 `work/settings-backup/<时间>/`，配置文件权限 0600。
若项目的 systemd 键盘服务正在运行，应用变更时会短暂重启它，以加载保存的配置。
保存或重启失败时会显示错误通知，不能视为设置已生效。

| 功能 | 状态 |
|---|---|
| 全拼、繁简转换 | 已验证候选词变化 |
| 小鹤双拼、自然码、86 五笔 | 已验证官方引擎的对应输入 |
| 模糊音、纠错、云候选等其他键盘引擎选项 | 会合并已有键盘字段的修改，但未逐项验证实际输入行为 |
| 表情开关 | 已知限制：关闭后部分候选仍出现表情 |
| 候选翻页键 | Linux 桥接代码固定为 `-` 上一页、`=` 下一页；原生翻页键选项不控制此行为 |
| 每页候选数量、候选排列 | Linux 桥接代码固定每页最多 9 项，并请求纵向排列；原生设置不控制这些显示行为 |
| Windows 语音页面 | 麦克风 ID、热键、标点选项尚未映射到 Linux 语音组件 |
| Windows 外观页面 | 候选框由 Fcitx 绘制，未映射官方字号和状态栏设置 |
| 官方键盘前端快捷键 | 部分行为由 Fcitx 处理，不保证全部官方开关生效 |
| 账号/词库同步 | 未验证 |
| 自动更新 | 设置副本中关闭，避免升级固定版本；升级需重新验证 RPC |

上述已验证的引擎选项见[验证记录](validation.md)。中英文切换和候选框外观由 Fcitx 管理，
Linux 语音快捷键及录音选项见[语音说明](voice.md)。

`python3 bridge/settings.py --check` 只检查所需文件。
不要把设置 prefix 与键盘 prefix 链接在一起；两个运行环境必须独立。
如果使用非 systemd 管理的键盘进程，应先停止该进程再修改设置，应用后自行重新启动。

恢复配置：关闭设置窗口，停止键盘服务，将对应备份的 `pre-apply.json`
恢复到活动 prefix 中当前用户的 `AppData/Roaming/DoubaoIme/conf/config.json`，再启动服务。
不要在运行中的引擎旁直接覆盖配置。
